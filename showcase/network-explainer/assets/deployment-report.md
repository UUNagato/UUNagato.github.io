结论：专用参数读取和统一采样循环均显著降低 Image 编译耗时，组合最好。统一循环保留采样点、权重和累加顺序，将三个 evaluateUV 调用点合为一个。编译器内联后需要处理的推理代码减少，是与结果一致的机制解释；本轮没有直接测量编译器中间表示。数据 Pass 首次观察约 6 秒，仍可能决定全新缓存环境的总编译下限，不能将 3.15 秒当作完整冷启动保证。

计时没有清理缓存。旧版本轮先测，各候选第一次出现，数据 Buffer 可命中缓存；因此同时列出 Image 分项。相同源码复测只用作功能回归，不当成首次编译收益。首次绘制可能还有驱动工作，所有帧的墙钟和 GPU 时间均保存在结果中。

复现：使用 round5_compile/run.ps1 执行 prepare.py，运行 server.mjs，在浏览器打开 http://127.0.0.1:8778/?auto=1；完成后执行 select_candidate.py 加候选名，刷新本地测试页完成全部回归，执行 finalize.py 打包。重新 prepare 会重置本轮候选和测试队列，应先保留已有结果。
