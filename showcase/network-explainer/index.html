Tiles encode numbers, not RGB images. Darker hidden-layer tiles indicate larger absolute activations; hues distinguish positive and negative values.

Math and decoding details 41 → 80 → 80 → 80 → 3

Pixel coordinates use uv = ((x + 0.5) / 512, (y + 0.5) / 512). At each level, grid coordinates are uv × size − 0.5, with clamped boundaries. Fine-grid features are concatenated in top-left, top-right, bottom-left, bottom-right order; coarse-grid features are interpolated by distance.

Position frequencies are 64, 128 and 256 cycles, each producing sin(x), sin(y), cos(x) and cos(y). Hidden layers compute h = sin(30 × (Wh + b)); the output layer maps linearly to RGB, then clamps to [0, 1].

The JavaScript decoder reads the actual model.bin. Floating-point accumulation differs slightly from the GPU; full-image metrics use the verified RGB8 reconstruction. Display resizing reconstructs the trained pixels before image resampling. Continuous reconstruction at arbitrary coordinates is not assumed.

03 / BETTER CODES, SAME BUDGET

Better quality.
Not one extra bit.

Same architecture, bit depths and data size.
Optimize the integer codes that go into the file.

  1. 01
    Fit the source image

    Learn local features and the decoder together. Each target image has its own parameters.

  2. 02
    Quantize and fine-tune

    Store grids at 4 bits and weights at 10 bits, then adapt to the actual storage precision.

  3. 03
    Choose better integer codes

    Try −1, unchanged and +1 for each grid code. Compare errors in affected pixels and accept only improvements.

Round 17 GLSL source is 924,067 bytes, separate from the 261,526-byte packed codec. At native 512², subsequent frames had a median GPU time of about 22.5 ms on the tested machine.
