展开数学与解码细节 41 → 80 → 80 → 80 → 3

像素坐标使用 uv = ((x + 0.5) / 512, (y + 0.5) / 512)。每级网格坐标为 uv × size − 0.5，边界取值 Clamp。细网格四点直接拼接；粗网格与高精度网格分别双线性插值。高精度值按 code / 65535 解码，插值后减去 0.5 作为网络输入，不直接叠加到输出。

位置编码频率为 64、128、256 cycles，分别产生 sin(x)、sin(y)、cos(x)、cos(y)。隐藏层为 h = sin(30 × (Wh + b))，输出层线性映射到 RGB 后限制在 [0, 1]。

此处 JavaScript 解码器从真实的 model.bin 读取参数，浮点累计与 GPU 存在细微差异；全图指标来自已验证的 RGB8 重建。改变显示大小时先还原训练像素，再做图像重采样，不假设网络具有任意坐标的连续重建能力。

03 / ENCODING THE IMAGE

图像如何
变成编码？

从图像拟合到量化，再到整数编码搜索。
这些步骤决定模型如何存储和还原图像。

  1. 01
    针对原图拟合

    高精度网格用图像块均值初始化，再与其他特征和网络共同训练。训练后不要求保留底色含义。

  2. 02
    量化与解码器微调

    两级网格使用 4-bit，高精度网格使用 16-bit，网络权重使用 10-bit；固定网格后微调解码器。

  3. 03
    直接挑选更好的编码

    4-bit 编码尝试相邻值，高精度编码尝试多种步长；后段还联合搜索 4-bit 通道对，按当前目标保留更好的选择。

    q − 1qq + 1
